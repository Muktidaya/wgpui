# wgpui-kit-assets

Default Lucide icons for WGPUI Kit 0.6.1, ported from Longbridge GPUI Kit.
Use `wgpui_kit::assets` through Kit's default `assets` feature, or depend on
this package directly. It exports `Assets`, `AllAssets`, `IconName`, and
`icon_assets!` for selecting an icon subset.

The package now lives in https://github.com/Muktidaya/wgpui and uses the
Cargo metadata identity `wgpui-kit-default-icons`. Its native runtime is
WGPUI 0.3.6. Existing `wgpui-component-assets` releases remain unchanged.
