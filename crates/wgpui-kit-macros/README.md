# wgpui-kit-macros

Procedural macros supporting WGPUI Base and styled components, adapted from
Longbridge GPUI Kit v0.8.1. Applications normally consume these through
`wgpui-kit`; this package is an implementation dependency.

The current source candidate is **wgpui-kit-macros 0.8.1** for the
**WGPUI Kit 0.8.1** and **WGPUI 0.4.0** source line, with **Rust 1.95**
as the minimum. Candidate validation and publication are in progress.
Published Kit-family 0.6.1 and framework 0.3.6 releases remain separate;
see [release status](../../STATUS.md).

The implementation lives at `crates/wgpui-kit-macros` in the
[consolidated WGPUI repository](https://github.com/Muktidaya/wgpui).
See the [Kit guide](../../docs/kit.md) for package paths and compatibility.
