# wgpui-component-assets

Default Lucide icon bundle for [`wgpui-component`](https://github.com/Muktidaya/wgpui-component) **0.6.0**.
Muktidaya adaptor of Longbridge `gpui-kit-assets` at gpui-component v0.6.0; the published crate name remains `wgpui-component-assets`. Depends on independently versioned **wgpui 0.3.5**.

```toml
[dependencies]
wgpui = "0.3.5"
wgpui-component-assets = "0.6.0"
```

The Cargo `links` identifier is still `gpui-kit-default-icons` so upstream
`icon_named!("$GPUI_KIT_DEFAULT_ICONS_DIR")` keeps resolving.
