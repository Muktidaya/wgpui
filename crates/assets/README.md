# wgpui-component-assets

Default Lucide icon bundle for [`wgpui-component`](https://github.com/Muktidaya/wgpui-component).
Tracks Longbridge `gpui-kit-assets` at gpui-component v0.6.0; the published
crate name remains `wgpui-component-assets`.

The Cargo `links` identifier is still `gpui-kit-default-icons` so upstream
`icon_named!("$GPUI_KIT_DEFAULT_ICONS_DIR")` keeps resolving.
