# wgpui_derive

Proc macros for [wgpui](https://crates.io/crates/wgpui): `Action`, `IntoElement`, `Render`, `AppContext`, `VisualContext`, `register_action`, style helpers, and (optional) inspector reflection.

Depend on `wgpui`; this crate is pulled in as a dependency. Generated code always uses the `wgpui::` path.

```toml
[dependencies]
wgpui = "0.3.6"
```
