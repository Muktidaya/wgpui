# wgpui-component-macros

Proc macros for [`wgpui-component`](https://github.com/Muktidaya/wgpui-component) **0.6.0** (adaptor of Longbridge `gpui-component-macros` onto [wgpui](https://github.com/Muktidaya/wgpui) 0.3.5).

Applications should depend on `wgpui-component`; this crate is pulled in automatically.

```toml
[dependencies]
wgpui = "0.3.5"
wgpui-component = "0.6.0"
```
