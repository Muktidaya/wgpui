# Historical reference contributions

This directory preserves the GPUI Component / Kit v0.6.0 reference baseline at
commit `94a313a72a2513aee2780240cd322d552b2395f0`; see
[`vendor/UPSTREAM_SHA`](vendor/UPSTREAM_SHA). It is excluded from the active Cargo
workspace and published WGPUI packages.

For current development, follow the [repository guidance](../AGENTS.md),
[WGPUI README](../README.md), [Kit guide](../docs/kit.md) and
[release status](../STATUS.md). This reference directory does not provide a
separate current build, contribution or publication workflow.

Its implementation, manifests, licenses, [Design Guides](website/docs/design-guides.md)
and [Coding Guides](website/docs/coding-guides.md) remain historical reference material.
