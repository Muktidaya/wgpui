to `94a313a72a2513aee2780240cd322d552b2395f0` in
[`vendor/UPSTREAM_SHA`](vendor/UPSTREAM_SHA). It is excluded from the active Cargo
workspace and published WGPUI packages.

Apply the current [repository AGENTS.md](../AGENTS.md) when working in this
repository. Use the [WGPUI README](../README.md), [Kit guide](../docs/kit.md) and
[release status](../STATUS.md) for current architecture and acceptance.

The retained source, manifests, licenses, [Design Guides](website/docs/design-guides.md),
[Coding Guides](website/docs/coding-guides.md) and [architecture](docs/ARCHITECTURE.md)
are historical references. This file does not select a toolchain or define a
separate development, testing or publication workflow.
