# Historical GPUI Component v0.6.0 reference

This directory retains historical reference source from the GPUI Component / Kit
v0.6.0 baseline, pinned to commit `94a313a72a2513aee2780240cd322d552b2395f0` in
[`vendor/UPSTREAM_SHA`](vendor/UPSTREAM_SHA). It includes the earlier adapted
source and retained upstream guides; it is not the current WGPUI implementation.

The directory is excluded from the active Cargo workspace and published WGPUI
packages. Its source, manifests, licenses and guides are reference material and
do not define current package versions, supported features or release acceptance.

Use the current [WGPUI README](../README.md), [repository guidance](../AGENTS.md),
[Kit guide](../docs/kit.md) and [release status](../STATUS.md).

The retained [Design Guides](website/docs/design-guides.md),
[Coding Guides](website/docs/coding-guides.md),
[architecture](docs/ARCHITECTURE.md) and [license](LICENSE-APACHE) remain available
for understanding this historical source.
